# GoPack: Gestión de Envíos ⌯⌲

Aplicación móvil diseñada para la gestión de paquetería y correo certificado. Bajo el lema *"Gestiona, envía, relájate"*, la app cuenta con una mascota propia que guía al usuario, aportando un toque visual único y divertido a una herramienta de gestión tradicional.

> **Contexto:** Desarrollé este proyecto como práctica para la asignatura de **Programación multimedia y de dispositivos móviles** del grado de **DAM**. El objetivo técnico era dominar la navegación mediante menús desplegables y la creación de formularios interactivos. El diseño de la interfaz (UI) y las ilustraciones originales están creadas desde cero para ofrecer la mejor Experiencia de Usuario (UX).

## Estado del proyecto

**Finalizado.** Proyecto educativo completado con sus pantallas de gestión y diseño UI/UX totalmente implementados.

## Características y Tecnologías

- **Animación dinámica de portada:** La pantalla principal incorpora una animación continua donde caen distintos paquetes y cartas de forma aleatoria, aportando vida a la interfaz.
- **Navegación dinámica:** Acceso rápido a las distintas secciones de la aplicación mediante un menú superior desplegable.
- **Panel de recepción:** Pantalla de control que contabiliza y muestra visualmente el total de correos certificados recibidos en la sucursal.
- **Envío de paquetes:** Formulario que recoge información clave (remitente, destino, dimensiones y peso máximo), incluyendo un *checkbox* interactivo para asegurar el envío.
- **Correo certificado:** Pantalla adaptada para envíos postales, que incluye un menú desplegable (*spinner*) para seleccionar el tamaño del paquete o sobre.
- **Tecnologías:** Desarrollado en **Kotlin** para Android, enfocado en el manejo de *inputs* de texto, validación visual de formularios, navegación entre vistas y programación de animaciones. Probado en emuladores *Medium Phone*.
