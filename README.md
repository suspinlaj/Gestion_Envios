# 📦 **GoPack: Gestión de Envíos**

**GoPack** es una aplicación móvil diseñada para simplificar la gestión de paquetería y correo certificado. Bajo el lema *"Gestiona, envía, relájate"*, la app cuenta con una mascota propia que guía al usuario por los distintos trámites, aportando un toque visual único y divertido a una herramienta de gestión tradicional.

## 📘 **Acerca de este proyecto**

Desarrollado como práctica para la asignatura de **Programación multimedia y de dispositivos móviles**. El objetivo principal técnico de este proyecto era dominar la navegación mediante menús desplegables y la creación de formularios interactivos para la recogida de datos. El diseño de la Interfaz (UI) y las ilustraciones originales están creados desde cero para ofrecer la mejor Experiencia de Usuario (UX).

## 🔧 **Funcionalidades**

- **Menú de Navegación Dinámico:** Acceso rápido a las distintas secciones de la aplicación mediante un menú superior desplegable.
- **Panel de Recepción:** Una pantalla de control que contabiliza y muestra visualmente el total de correos certificados recibidos en la sucursal.
- **Formulario de Envío de Paquetes:** Interfaz de entrada de datos que recoge información clave (Remitente, Destino, Dimensiones y Peso máximo), incluyendo un *checkbox* interactivo para asegurar el envío.
- **Formulario de Correo Certificado:** Pantalla adaptada para envíos postales, que incluye un menú desplegable (*spinner*) para que el usuario seleccione el tamaño del paquete o sobre.

## 💻 **Tecnologías y Entorno**

- **Lenguaje**: Kotlin
- **Entorno de pruebas / Emulador**: Medium Phone
- **Enfoque destacado**: Manejo de inputs de texto, validación visual de formularios y navegación entre vistas.

## ⚙️ **Estado del proyecto**

Finalizado. Proyecto educativo completado con sus pantallas de gestión y diseño UI/UX totalmente implementados.
